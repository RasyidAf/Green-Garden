# 🌿 Green Garden - Gardening Service Landing Page

A modern, responsive, and highly interactive landing page for a professional gardening and landscaping service company. Built with vanilla web technologies, this project prioritizes elegant UI/UX animations, performance, and maintainability.

## ✨ Features

- **Modern UI Animations**: Features beautiful page-load entrance keyframes, staggered scroll-reveal animations using `IntersectionObserver`, and smooth micro-interactions on hover (cards, buttons, project gallery zoom).
- **Dark Mode Support**: Includes a seamlessly integrated dark mode toggle with CSS Variables. The user's theme preference is saved in `localStorage`.
- **Custom Testimonial Carousel**: A dynamic, JavaScript-powered client review carousel with smooth fade transitions and auto-generated indicator dots.
- **Mobile Responsive**: Fully responsive layout adopting CSS Flexbox with an elegant slide-in mobile sidebar menu.
- **Optimized for Performance & SEO**: Includes lazy loading (`loading="lazy"`) for gallery images to improve initial render time, along with complete Meta Tags and Open Graph data for social media sharing.
- **Accessibility Enhancements**: Utilizes semantic HTML structure and proper `alt` text for images.

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and SEO-friendly structure.
- **CSS3**: Advanced styling leveraging CSS Variables (Custom Properties), Flexbox layout, media queries, CSS transitions, and `@keyframes` animations.
- **Vanilla JavaScript (ES6+)**: Handles the custom carousel logic, Dark Mode toggles, back-to-top scroll detection, and `IntersectionObserver` for viewport animations.

## 🚀 How to Run

Since this project relies entirely on static, vanilla web technologies, no build tools or package managers are required.

1. Clone or download the repository to your local machine.
2. Open the `Green-Garden` directory.
3. Simply double-click on `index.html` to open it in your default web browser.
4. *(Optional)* For the best development experience, open the folder in an IDE like VS Code and use the **Live Server** extension to serve the files locally.
